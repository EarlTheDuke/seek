model can be believed.** Every previous run welded each model to one seat, one

## The bug this run found, which no harness could have

Ailsa ate FOUR venison in 8.2 seconds; Coinneach four in 7.1. One decision was
eating the whole pack, in a valley where meat is the entire problem, with the
belly full by the third.

`eatCooling` was working — it stops a body swallowing twice in a TICK. It does
not stop a STANDING GOAL firing again the moment it lapses. Fixed mid-run
(`ab5c3c9`): a decision to eat is honoured by eating once, a fresh decision is
still fed. **This journal is the pre-fix behaviour** and should be read that way;
the bursts should not appear again.
